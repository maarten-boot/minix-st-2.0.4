* Four agents, one per open item from the end of Follow-up 65: A INET
  psip (oversized packets), B INET TCP (cancelled listen, low ports),
  C lib/ip ruserok and gethostent, D the kernel panic on a user bus
  error. INET fixes are fixed copies in `src/rosco/boot/inetfix/` (src/inet

* **C: lib/ip ruserok.c** (fixed copy `src/rosco/lib/ruserok.c`):
  * a missing /etc/hosts.equiv (the card has none) returned -1 before
    ~/.rhosts was opened, so .rhosts never worked;
  * the superuser argument was ignored on purpose (and every caller
    passes 0), so a host in hosts.equiv also trusted root, against
    ROSCO_M68K_USAGE.md;
  * .rhosts had no owner or mode check;
  * a last line without a newline was skipped as "too long".
  * Now as in BSD: a local user with uid 0 is the superuser whatever the
    caller passes; hosts.equiv is skipped for root and when missing;
    then ~/.rhosts (root: /.rhosts), which must be a regular file owned
    by the user or root, not writable by group or others.
* **C: lib/ip gethostent.c** (fixed copy): a last /etc/hosts line without
  a newline was lost. Lines of 256 characters or 16 words and more are
  still skipped; the lines after them are kept. gethostent is used by
  nonamed only (the resolver goes through nonamed).
* No -mshort traps in either file.
* Relinked: in.rshd, in.rlogind, nonamed.
* Tested in MAME over SLIP: a Python rsh client from reserved ports in
  the container against in.rshd, original vs fixed:
  * no hosts.equiv, /.rhosts and ~ast/.rhosts: refused → accepted (root
    and ast);
  * ~ast/.rhosts mode 666, or owned by bin: refused;
  * hosts.equiv "host", no .rhosts: ast accepted, root accepted →
    refused; with /.rhosts too, root accepted;
  * a .rhosts line without a newline: refused → accepted;
  * `nc lasthost` with lasthost on a last /etc/hosts line without a
    newline: "unknown host" → connects.
* Notes: in.rshd, in.rlogind and in.rld still pass 0 as superuser (the
  library works it out now); a "host user" line in hosts.equiv admits
  that remote user as any non-root local user, as in BSD.
