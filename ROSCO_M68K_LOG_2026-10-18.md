    even while the owner waits for FS.

    every address below the end of the data as "data" and moved it, but
    only data and stack are shadowed. Text stays, and string constants and
    const data are in text (ACK's and gcc's rodata both).

    the replay that "lost" the failure had reused an image the run before
    had written to; disk state was not the cause.

    (process the script first) makes headless breakpoints with actions
    (`logerror`, `save`) work; it is uncommitted there, for the user.
  * Breakpoints at FS `do_stat()` (FS at 0x18500): `user_path` was empty

    source 0x47c30 instead of 0x81a30 for f4 only. The proc table from the

  data base up (`src/kernel/system.c`).
